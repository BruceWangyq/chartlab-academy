## 详细发现

### P1 — 多页面辅助文字未达到 WCAG AA 对比度

- 位置：`src/app/globals.css` 的课程工作区、练习实验室、Dashboard、复盘和定价辅助文字规则。
- 影响：低视力、低亮度设备及强光环境下难以阅读课程编号、表单说明、保存状态和法律续费说明。
- 标准：WCAG 2.2 SC 1.4.3。
- 实测：完整 axe 扫描在 `/pricing`、课程页、练习页、Dashboard 和 `/review` 检出 `color-contrast`。
- 修复方向：把辅助文本统一收敛到经验证的深色令牌，并保留语义状态色的足够对比。

### P1 — 正文中的法律和升级链接只依赖颜色

- 位置：`src/app/globals.css` 中 `.pricing-terms a` 与 `.account-page > header > small a`。
- 影响：色觉差异用户无法可靠区分链接与正文。
- 标准：WCAG 2.2 SC 1.4.1。
- 实测：`/pricing` 和 `/review` 检出 `link-in-text-block`。
- 修复方向：为正文链接增加持续下划线和足够的下划线偏移。

### P1 — 练习帮助弹窗焦点逃逸且关闭后不恢复

- 位置：`src/components/practice-lab.tsx` 的 `practice-help` 对话框。
- 影响：键盘及屏幕阅读器用户按 Tab 后会进入被遮罩的后台页面；Escape 关闭后失去操作位置。
- 标准：WCAG 2.2 SC 2.4.3、2.4.11；ARIA Dialog Modal Pattern。
- 实测：打开后首焦点正确，但下一次 Tab 离开对话框，关闭后触发按钮未恢复焦点。
- 修复方向：保存触发元素、拦截首尾 Tab、关闭时恢复焦点。

### P1 — 首页图表运行时拖慢最大内容绘制

- 位置：主页首屏的两个 Lightweight Charts 客户端实例与同意提示竞争主线程和最大内容绘制。
- 影响：首次 Lighthouse 性能 85，LCP 3480ms、TBT 277ms，未达到 LCP < 2.5s、TBT < 200ms 的发布门禁。
- 修复方向：首页改为服务端生成的可访问静态 SVG；仅在真正需要交互的学习与练习页加载图表运行时。

### P2 — 颜色规则未完全令牌化

- 位置：`src/app/globals.css`。
- 影响：相同辅助文本在不同表面使用相近但不一致的灰蓝色，后续更改容易再次引入对比回归。
- 修复方向：新增辅助文字、深色表面辅助文字和正文链接令牌，用自动 WCAG 回归锁定结果。

### P2 — 若干紧凑控件低于 44px 建议尺寸

- 位置：课程动作、案例数字输入、标签按钮和筛选控件。
- 影响：触控用户的误触概率增加；当前仍高于 WCAG 2.2 AA 的 24px 最低目标，但不符合项目更高的移动体验目标。
- 修复方向：移动/粗指针环境统一把主要表单控件扩展到至少 44px。

## 系统性模式

- 辅助文字颜色来自多个接近的硬编码值，而非一个通过对比验证的语义令牌。
- 现有 E2E 只阻止 serious/critical axe 违规且只覆盖三个公开页面，未覆盖登录后的核心学习区。

## 正向证据

- 跳转主内容、可见焦点、语义导航、表单标签、ARIA 状态和错误播报已广泛使用。
- 图表有文字说明与最近 10 根 K 线表格；练习可以完全不依赖拖拽完成。
- 已支持 reduced motion、200% 缩放、键盘提交、移动端无溢出和颜色之外的文字标签。
- 视觉方向与 PRD 一致：深夜蓝专注区、浅色阅读面、克制的靛蓝动作色，没有收益承诺或交易终端拟态。

## 修复顺序

1. P1 `/normalize`：统一语义文字与正文链接规则，消除完整 WCAG 扫描结果。
2. P1 `/harden`：修复对话框焦点约束和恢复。
3. P1 性能：把首页展示型图表改为服务端静态 SVG，并锁定 Lighthouse 指标。
4. P2 `/adapt`：扩大粗指针环境下的紧凑控件。
5. P3 `/polish`：完成修复后的视觉和跨浏览器复核。

修复后必须重新执行完整 axe、键盘对话框、跨浏览器、200% 缩放、窄屏和性能预算检查；本文件随后更新为最终分数。

### 已关闭问题

- P1 对比度：统一为经验证的辅助文字/深色表面/状态色令牌，完整 axe 回归零违规。
- P1 正文链接：定价法律链接与账户内升级链接增加持续下划线。
- P1 弹窗焦点：保存并恢复触发元素，Tab 循环和 Escape 关闭均有跨浏览器测试。
- P2 触控尺寸：粗指针环境下课程、筛选、练习、设置等主要控件统一达到至少 44px。
- 性能回归：主页移除 Lightweight Charts 客户端运行时，改用可访问的静态 SVG；交互图表仍保留在真正需要操作的页面。
