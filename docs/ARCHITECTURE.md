# 架构说明

## 边界

应用采用 Next.js 16 App Router 模块化单体。公开内容、登录学习系统和业务 API 在同一代码库，MVP 不拆微服务。

## 数据权威源

| 领域 | 权威源 | 本地降级 |
| --- | --- | --- |
| 课程、文章、作者、SEO | Sanity | `src/lib/content.ts` / `library.ts` 首发种子内容 |
| 用户、进度、订阅、练习、审计 | Postgres | 浏览器 localStorage 仅用于无凭据演示 |
| 账单 | Stripe | 无；未配置时明确禁用结账 |
| 视频 | Mux | 当前课程文字和历史图表仍可学习 |
| 图表数据包 | 对象存储/授权数据 | 可复现的教学模拟数据生成器 |

## 核心请求路径

1. 公开课程页静态生成，后续可由 Sanity 发布 Webhook 定向刷新。
2. 邮箱 OTP 或 Google OAuth 先按邮箱复用 Postgres 用户，再建立签名 HttpOnly 会话。
3. 受保护接口逐请求重新解析数据库角色、有效订阅和人工权益，不依赖前端隐藏按钮或会话中的旧权益。
4. 课程进度、收藏、笔记、测验、练习草稿和提交写入 Postgres；未配置数据库时浏览器副本只承担本地演示降级。
5. 练习提交由服务端 Zod 校验并用确定性规则评分；客户端只负责编辑和展示。
6. Stripe Checkout 只接受 `monthly` / `annual` 内部 plan key，实际 Price ID 只从服务端环境读取。
7. Stripe Webhook 验签后先原子认领唯一事件记录，再更新订阅镜像；已处理事件幂等返回，失败事件可重放，超过 5 分钟的处理中事件可安全回收。
8. 每日定时任务按稳定 ID 分页读取所有本地 Stripe 订阅镜像，以最多 5 个并发请求回查 Stripe；状态、套餐或周期漂移会自动修正并写入审计日志，单条失败不阻断其余订阅。
9. Mux 播放令牌仅对具有 Pro 权益的登录用户签发，5 分钟失效。
10. 免费账户登录后每个自然月可使用 5 个不同案例，重复练习不重复计数；服务端事务锁防止并发绕过，Pro 不限量。
11. 分析事件在 `required` 模式下必须先取得同意，拒绝不会创建匿名或会话标识符，也不影响学习功能。
12. 账户导出只包含用户可读数据；删除先停止续费，30 天后清除学习数据并匿名化，保留期到期后再清理最小账务镜像和去标识审计。
13. 首页行情示意使用服务端生成的静态 SVG，保留蜡烛图与成交量语义且不发送图表运行时；课程、测验和练习页才按需加载可交互图表，避免教学工具拖慢首次访问。

## 数据模型

迁移在 `drizzle/`。14 张表覆盖：用户/画像、订阅/权益、课程参与/进度、测验、案例/尝试/标注、笔记/收藏、Webhook 幂等和审计日志。

## 安全

- HttpOnly、SameSite=Lax、生产 Secure Cookie
- CSP、禁止 iframe 嵌入、MIME sniffing 防护、权限策略
- Webpack 构建期 SRI 为关键 Next.js 脚本附加 SHA-256 完整性；CSP 与 SRI 的兼容边界记录在验收矩阵
- Webhook/CMS 请求签名或密钥校验
- 服务端 Zod 校验和固定价格映射
- 付费课程和视频在服务端校验 Pro 权益；案例在服务端校验登录、自然月免费额度或 Pro 权益
- 登录验证码、验证码校验、结账和练习提交按来源与主体限流
- 练习自由文本、笔记和支付敏感数据不发送到分析平台
- 生产 `AUTH_SECRET` 不足 32 字符时拒绝建立会话；未配置的外部服务默认关闭

## 可观测性

Next.js instrumentation 会输出不含请求正文和用户内容的结构化启动/请求失败日志，并把服务端异常发送至 Sentry；客户端 SDK 在首屏加载完成后延迟启用，避免突破公开页 JavaScript 预算。生产 `/api/health` 需要独立 Bearer Secret，检查应用与数据库但不公开连接信息；PostHog 只在同意策略允许时接收产品事件与 LCP/INP/CLS。生产环境把日志接入 Vercel Log Drain，并按 Runbook 的 P0/P1 阈值配置告警。客户端全局错误页允许安全重试，不会清除浏览器中的练习草稿。

本地发布门禁还会对生产构建运行 Lighthouse：性能至少 90、无障碍 100、最佳实践至少 95、SEO 100，并要求 LCP < 2.5 秒、CLS < 0.1、TBT < 200 毫秒。
